About this data

Extracted from DICOM Part 16

All SR template definitions and context group references are parsed directly from the DICOM Standard Part 16 CHTML pages using an automated Python pipeline.

The graph shows 386 Structured Reporting Templates (TIDs) and their include and context group reference relationships. Node sizes reflect connectivity degree. Source data is regenerated with each new DICOM edition.
