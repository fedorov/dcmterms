About this data

Extracted from DICOM Part 16

All coded terminology is parsed directly from the DICOM Standard Part 16 CHTML pages using an automated Python pipeline. The 1,466 Context Groups (CIDs) are traversed and their coded entries consolidated into a searchable table.

Codes from 21 coding schemes are included: SNOMED CT, DCM, LOINC, UCUM, NCIt, RADLEX, and more. Code-to-CID membership is preserved so you can trace any concept back to its source context groups.
