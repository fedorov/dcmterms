About this data

Extracted from DICOM Part 16

All content is parsed directly from the DICOM Standard Part 16 CHTML pages using an automated Python pipeline. The 1,467 Context Groups and 386 SR Templates are extracted and consolidated into structured, searchable resources.

Data is regenerated with each new DICOM edition and published here as Parquet files queryable directly in the browser via DuckDB-WASM.

Open source on GitHub ↗  ·  Questions? File an issue ↗

The DICOM Standard defines the rules of play — and dictates the terms. But with over 14,000 coded concepts spread across 1,467 Context Groups and 386 Structured Reporting Templates in Part 16, navigating those terms is no small feat. dcmterms turns that sprawl into searchable, interactive tools… or at least some parts of it!
